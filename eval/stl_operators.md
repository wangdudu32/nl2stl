## STL

### 1、原子谓词

#### 定义

**原子谓词**是作用在信号上的**基本断言**或**条件**，形式为：
$$
\mu(x) := f(x) \sim c
$$

其中：

- x: 是一个**实值信号**（或信号向量）
- f: 是一个函数（通常很简单）
- ~: 是比较运算符
- c: 是一个常数阈值

#### 关键特性

1. **输入是实值信号**：处理的是连续或离散的数值数据
2. **输出是布尔信号**：在每一个时间点 t，原子谓词评估为 `True` 或 `False`

3. **无时序成分**：只关心当前时刻的信号值，不涉及时间关系

### 3、带时间区间的时序算子

#### 时序算子

##### a、基础 STL 算子

###### 1. always

```
always（始终/全局） 
```

- **符号**: `always[a,b]φ`
- **含义**: always[a,b]`φ`表示“在**整个时间区间 [a,b] 内**，**所有时刻** `φ` 都为真。” 
- **例子**: `G[0,30](speed < 60)`
  “在30秒内，速度始终低于60”



###### 2. eventually

```
eventually（最终/未来某刻）
```

- **符号**: `eventually[a,b]φ`
- **含义**: `eventually[a,b]φ表示"在时间区间 I 内，φ 至少成立一次"`
- **例子**: `eventually[5,15](arrive_destination == true)`
  “在未来的5到15秒之间的某个时刻，(arrive_destination == true)会成立”



###### 3. until

```
 until（直到）
```

- **符号**: `φ₁ until[a,b] φ₂`
- **含义**:  `φ₁ until[a,b] φ₂表示"在时间区间[a,b]内，∃c∈[a,b]，使得在[a,c) φ₁ 一直为真，在时刻 c 时 φ₂ 变为真"`
- **例子**: `(temperature > 20) until[0,10] (alarm == true)`
  “∃c ∈[0,10]，使得在[0,c) `(temperature > 20)` 一直为真，在时刻 c 时 `(alarm == true)` 变为真”



###### 4. weak_until

```
weak_until（弱直到）
```

- **符号**: `φ₁ weak_until[a,b] φ₂`
- **含义**: `φ₁ weak_until[a,b] φ₂` 表示"在时间区间 [a,b] 内，要么 φ₁ 一直为真直到 φ₂ 为真，要么 φ₂ 在整个区间内从未为真而 φ₁ 始终为真"
- **例子**: `(send_heartbeat == true) weak_until[0,10] (ack_received == true)`
  “系统将持续发送心跳信号，直到收到确认信号或时间超过10秒（即使未收到确认）"



###### 5. release

```
release（释放） （until的对偶）
```

- **符号**: `φ₁ release[a,b] φ₂`
- **定义**: `¬(¬φ₁ until[a,b] ¬φ₂)`（until的对偶算子）
- **含义**: `φ₁ release[a,b] φ₂` 表示"在时间区间 [a,b] 内，*ψ* 必须一直为真，除非 ϕ 发生（ϕ 发生时刻及之后，ψ 不再强制为真）；如果 ϕ 从未发生，那么 ψ 必须在整个区间内为真。"
- **例子**: `(system_state == normal) release[0,∞] (mode == safe_mode)`
  “安全模式必须一直保持，直到系统正常运行为止”

### 4、扩展STL算子

##### a、过去时态算子

```
经典STL通常只面向未来，但扩展后会加入过去算子。
```

###### 6. once

```
Once（过去某刻）
```

- **符号**: `once[a,b] φ`
- **含义**: `once[a,b] φ` 表示"在**过去的**时间区间 [a,b] 内，**存在某个时刻** φ 为真"
- **例子**: `once[0,5](button_pressed == true)`
  “在过去的5秒内，按键曾被按下过”



###### 7. historically

```
historically（过去始终）
```

- **符号**: `historically[a,b] φ 或者 H(φ)`
- **含义**: `historically[a,b] φ` 表示"在**整个过去的**时间区间 [a,b] 内，**所有时刻** φ 都为真"；
- **例子**: `historically[0,10] (door_closed == true)`
  “在过去的10秒内，门一直关着”



###### 8. since

```
since（自从）
```

- **符号**: `φ₁ since[a,b] φ₂ 或者 φ₁ since φ₂`
- **含义**: `φ₁ since[a,b] φ₂` 表示"在过去的某个区间 [t−b,t−a] 内，存在一个时刻 t′，使得 ψ 在 t′ 处成立，并且从 t′ 开始一直到当前时刻 t，φ 都一直成立"；
- **例子**: `(temperature > 20) since[0,10] (heater_on == true)`
  “在 heater_on 变为真之后的过去10秒内，temperature 始终大于20”
- **直观理解**: since是 Until 在时间上的“过去版本”。



##### b. 边缘算子

###### 9. rise

```
rise（上升沿）
```

- **符号**: `rise(φ)`
- **含义**: `rise(φ)` 表示"布尔谓词 φ 从假（False）变为真（True）的瞬间"
- **离散时间视角**: 在时刻 t，`rise(φ)` 为真，当且仅当 φ 在上一时刻 t−1 为假，而在当前时刻 t 为真

$$
\mathit{rise}(\varphi) \equiv \neg\varphi_{t-1} \wedge \varphi_t
$$

- **连续时间视角**: `rise(φ)` 发生在 t，当且仅当 x(t) = c 且 x 的导数 ẋ(t) > 0（即信号正在向上穿越阈值）
- **例子**: `rise(RPM > 3000)`
  “发动机转速从<= 3000 变为 > 3000 的那个瞬间”



###### 10. fall

```
fall（下降沿）
```

- **符号**: `fall(φ)`
- **含义**: `fall(φ)` 表示"布尔谓词 φ 从真（True）变为假（False）的瞬间"
- **离散时间视角**: 在时刻 t，`fall(φ)` 为真，当且仅当 φ 在上一时刻 t−1 为真，而在当前时刻 t 为假

$$
\mathit{fall}(\varphi) \equiv \varphi_{t-1} \wedge \neg\varphi_t
$$

- **连续时间视角**: `fall(φ)` 发生在 t，当且仅当 x(t) = c 且 ẋ(t) < 0（信号向下穿越）
- **例子**: `fall(Temperature > 100)`
  “温度从过热状态回落到 100 度及以下的瞬间”



###### 11. peak

```
peak（峰值/局部最大值）
```

- **符号**: `peak(x)`
- **含义**: `peak(x)` 表示"信号 x 在时刻 t 达到局部最大值，即其导数 ẋ 从正变负"

$$
\mathit{peak}(x) \equiv (\dot{x}(t) = 0) \wedge (\ddot{x}(t) < 0)
$$

（在实际工具中，通常简化为：t 时刻的值大于 t−ε 和 t+ε 的值）
- **例子**: `peak(Voltage)`
  “电压出现局部最高点”
