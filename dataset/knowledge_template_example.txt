operator: <operator_name>
meaning: "<用一句话说明该算子或组合算子的 STL 语义。>"
cases:
  - semantic: "<概括这一类自然语言表达对应的时序语义。>"
    cue: "<自然语言线索片段>：<说明该片段如何对应算子语义。>"
    pattern: "<抽象后的 STL 结构模式>"

  - semantic: "<另一类语义差异明确的用法。>"
    cue: "<对应的自然语言线索片段>：<对应关系说明。>"
    pattern: "<另一种抽象 STL 结构模式>"

字段含义：
- `operator`: 算子名或连续组合算子名，组合算子用下划线连接，例如 `eventually_rise`、`not_fall_until`。
- `meaning`: 对该算子整体语义的定义，说明时间方向、窗口、有界/无界、持续/最终、转移事件或否定作用域。
- `cases`: 该算子的不同语义用法列表。只有语义确实不同的用法才新增 case。
- `semantic`: 抽象概括一类自然语言和 STL 结构的对应关系，不写具体样本编号，尽量不保留随机变量名和常数。
- `cue`: 保留或精简自然语言中支持该语义判断的关键片段，并在冒号后说明对应关系；不要编造原句没有支持的语义。
- `pattern`: 抽象 STL 结构，使用 `φ`、`ψ`、`x`、`c`、`lower`、`upper`、`[a:b]` 等占位符，不保留具体变量和随机数值。

示例：
```text
operator: eventually_rise
meaning: "eventually(rise(φ)) 表示未来某个时间点必须观察到谓词 φ 从 false 变为 true。"
cases:
  - semantic: "未来指定时间窗口内需要发生某个上升转移事件。"
    cue: "at sometime within the following b time units the scenario that x is shifted to c needs to take place：eventually 的目标不是普通状态，而是 rise 描述的转移事件。"
    pattern: "eventually [a:b] (rise(φ))"

  - semantic: "无界未来范围内最终发生指定上升转移事件。"
    cue: "There has to be a certain moment in the future before the simulation ends, at which finally the scenario that x gets set to c has to occur：未来某个时刻需要观察到 rise 事件。"
    pattern: "eventually(rise(φ))"
