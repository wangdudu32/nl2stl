domain: aerospace（航空航天）
scenario: altitude_hold（飞行引导系统高度保持）
signals:
    signal name: vertical_guidance_mode
    signal message: 飞行引导系统当前生效的垂直引导模式；模式既可能由飞行员选择，也可能由系统自动转换进入。
    signal role: mode
    type: Enum
    enum values:
        VERTICAL_SPEED:
            message: 垂直速度模式；飞行引导系统获取并保持选定的垂直速度。
        FLIGHT_PATH_ANGLE:
            message: 飞行航迹角模式；飞行引导系统获取并保持选定的垂直航迹角。
        AIRSPEED_MACH_HOLD:
            message: 空速或马赫数保持模式；保持模式接通时的指示空速或马赫数。
        AIRSPEED_MACH_SELECT:
            message: 空速或马赫数选择模式；获取并保持预先选择或接通时同步的空速或马赫数。
        FL_CHANGE:
            message: 飞行高度层改变模式；通过俯仰控制与推力控制协调完成爬升或下降。
        ALTITUDE_CAPTURE:
            message: 高度捕获模式；从其他垂直模式平顺过渡并捕获选定的目标高度。
        ALTITUDE_HOLD:
            message: 高度保持模式；保持飞行员选择模式时的高度，或自动捕获后保持选定高度。
        VNAV:
            message: 垂直导航模式；获取并保持飞行管理系统给出的垂直飞行路径。

    signal name: aircraft_vertical_speed
    signal message: 飞机当前的有符号垂直速度；正值表示爬升，负值表示下降。具体性能边界取决于机型、重量、高度和飞行状态。
    signal role: measurement
    type: float
    value domain: (-∞, +∞)
    reference range: [-6000, 6000]
    reference range purpose: predicate generation and value sampling
    reference range status: non-normative engineering reference
    unit: ft/min

    signal name: level_flight_vertical_speed_threshold
    signal message: 飞行引导系统判断飞机达到平飞状态时采用的最大垂直速度绝对值；FAA给出的约200 ft/min仅为示例判据，具体值可以由飞机设计确定。
    signal role: configuration
    type: float
    value domain: [0, +∞)
    unit: ft/min
    reference value: 200
    reference value status: example

    signal name: selected_altitude_error
    signal message: 自动从高度捕获转换到高度保持后，飞机当前高度相对于所选目标高度的有符号偏差；正值表示高于所选高度，负值表示低于所选高度。
    signal role: derived measurement
    type: float
    value domain: (-∞, +∞)
    unit: ft

    signal name: selected_altitude_tolerance
    signal message: 判断所选高度是否得到保持时允许的最大绝对高度偏差；具体数值由飞机设计、适航符合性方法或设备配置确定，当前资料未规定统一数值。
    signal role: configuration
    type: float
    value domain: [0, +∞)
    unit: ft

    signal name: annunciated_vertical_guidance_mode
    signal message: 飞行引导系统当前向机组显示的垂直引导模式；NONE表示没有显示可识别的垂直模式提示。
    signal role: displayed mode
    type: Enum
    enum values:
        NONE:
            message: 当前没有显示可识别的垂直引导模式提示。
        VERTICAL_SPEED:
            message: 当前显示垂直速度模式。
        FLIGHT_PATH_ANGLE:
            message: 当前显示飞行航迹角模式。
        AIRSPEED_MACH_HOLD:
            message: 当前显示空速或马赫数保持模式。
        AIRSPEED_MACH_SELECT:
            message: 当前显示空速或马赫数选择模式。
        FL_CHANGE:
            message: 当前显示飞行高度层改变模式。
        ALTITUDE_CAPTURE:
            message: 当前显示高度捕获模式。
        ALTITUDE_HOLD:
            message: 当前显示高度保持模式。
        VNAV:
            message: 当前显示垂直导航模式。

    signal name: barometric_datum_adjustment_active
    signal message: 高度基准气压是否正在调整；调整引起的飞机响应应当平顺。
    signal role: operating context status
    type: bool
    value domain: {false, true}

reference predicates:
    predicate name: altitude_capture_mode_active
    predicate message: 飞行引导系统当前处于高度捕获模式。
    predicate type: enum comparison
    expression: vertical_guidance_mode == ALTITUDE_CAPTURE

    predicate name: altitude_hold_mode_active
    predicate message: 飞行引导系统当前处于高度保持模式。
    predicate type: enum comparison
    expression: vertical_guidance_mode == ALTITUDE_HOLD

    predicate name: selected_altitude_error_within_upper_bound
    predicate message: 飞机高度没有高出所选高度允许容差以上。
    predicate type: numeric comparison
    expression: selected_altitude_error <= selected_altitude_tolerance

    predicate name: selected_altitude_error_within_lower_bound
    predicate message: 飞机高度没有低于所选高度允许容差以上。
    predicate type: numeric comparison
    expression: selected_altitude_error >= -selected_altitude_tolerance

    predicate name: altitude_hold_mode_annunciated
    predicate message: 飞行引导系统当前向机组显示高度保持模式。
    predicate type: enum comparison
    expression: annunciated_vertical_guidance_mode == ALTITUDE_HOLD

    predicate name: vertical_speed_below_level_flight_upper_bound
    predicate message: 飞机向上的垂直速度低于平飞判据上界。
    predicate type: numeric comparison
    expression: aircraft_vertical_speed < level_flight_vertical_speed_threshold

    predicate name: vertical_speed_above_level_flight_lower_bound
    predicate message: 飞机向下的垂直速度没有超过平飞判据下界。
    predicate type: numeric comparison
    expression: aircraft_vertical_speed > -level_flight_vertical_speed_threshold

    predicate name: barometric_datum_adjustment_in_progress
    predicate message: 高度基准气压当前正在调整。
    predicate type: boolean comparison
    expression: barometric_datum_adjustment_active == true

behavior notes:
    note: 飞行引导系统可以由高度捕获模式自动转换到高度保持模式；自动转换后，高度保持模式应引导或控制飞机保持选定高度。

    note: 从其他垂直模式自动转换到高度保持模式时，应向机组清晰显示该模式转换。

behavior notes:
    note: 如果在车辆速度低于约30 km/h时建立设定速度，系统会将设定速度设为约30 km/h。

    note: LONG、MEDIUM和SHORT对应的约50 m、40 m和30 m车距仅适用于80 km/h；实际目标车距会随车辆速度增大或减小。

    note: 当ACC无法充分自动减速以避免本车过度接近前车时，接近警告显示会闪烁，同时蜂鸣器会鸣响，提示驾驶员进行制动操作。

    note: 为形成互不重叠的有效速度段，本知识库在20 km/h至低于50 km/h时采用6秒标称时限，在不低于50 km/h时采用更严格的3.5秒标称时限；法规原始条文中的6秒条件写为车速不低于20 km/h。

behavior notes:
    note: 电池运行环境温度的知识库参考工作范围为用户确认的[-30, 60] °C；所引DOE/USABC资料中的Operating Environment目标为[-30, 52] °C，两者应在后续数据生成时保持来源状态区分。

    note: 高倍率充电目标“80% DSOC”表示SOC增加80个百分点，例如从10%增加到90%；它不是最终SOC等于80%，也不是充入额定容量80%的Ah或kWh计量值。

    note: 实测容量相对额定容量或工作容量的绝对偏差超过10%时，应在继续试验前通知技术经理并复核或重新定额。

    note: 过充或过放保护未自动切断相应电流时，法规试验程序使用温度条件、时间条件或标称电压25%等备用终止条件继续或终止试验；保护动作结果与备用终止条件应分别表达。

    note: 达到最大过流充电水平后，法规要求过流保护切断充电电流，或者REESS外壳温度在两小时内稳定到变化小于4 °C；两个原子条件的选择关系应在后续组合逻辑中表达。

    note: WHO硝酸盐和亚硝酸盐指导值分别按完整NO3-和NO2-离子质量计量，与美国饮用水标准中的“以氮计”浓度单位不同，不能直接比较数值而忽略换算。

    note: 制定氟化物国家标准时还应考虑当地饮水量以及食物、空气等其他来源的氟摄入。

    value domain: [0, +∞)
    reference range: sensing_system_and_risk_assessment_specific
    unit: mm

    signal name: protective_distance_violated

    signal role: derived hazard status

    value domain: {false, true}

    predicate name: human_approach_speed_within_reference_model

    predicate type: numeric comparison
    expression: human_approach_speed <= 2000
    unit: mm/s

behavior notes:
    note: protective_separation_distance由反应阶段的人机接近量、人员在机器人停止阶段的继续接近量、机器人停止距离和位置不确定度裕量组成；所有输入应对应同一运行条件。

    note: protective_distance_violated为真时所需的减速、保护停止或其他响应由应用风险评估确定；响应时限和持续时间应在生成STL时作为时序逻辑加入。

scenario: collaborative_robot_safety_limits（协作机器人安全限值与恢复模式）
signals:

scenario: mobile_robot_obstacle_avoidance（自主移动机器人障碍物探测与安全停车）
signals:
    signal name: mobile_robot_speed_fraction
    signal message: 自主移动工业车辆当前速度幅值除以额定最大速度所得的实际比例；0表示静止，1表示达到额定最大速度。
    signal role: derived motion measurement
    type: float
    value domain: [0, +∞)
    reference operating range: [0, 1]
    unit: ratio

    signal name: path_clearance
    signal message: 车辆运动轮廓外缘与相邻危险物或固定边界之间当前可用的最小横向净距实测值。
    signal role: measured environment clearance
    type: float
    value domain: [0, +∞)
    unit: m

    signal name: restricted_path_clearance_threshold
    signal message: 用于判定路径是否属于受限净距路径的配置阈值；参考资料以0.5 m作为判定界限。
    signal role: safety configuration threshold
    type: float
    value domain: [0, +∞)
    reference value: 0.5
    reference value status: NIST引用的受限路径净距判定值。
    unit: m

    signal name: restricted_path_speed_fraction_limit
    signal message: 危险环境或受限净距路径中配置的车辆最大速度比例上限；该值是限值配置，不是当前实际速度比例。
    signal role: safety configuration threshold
    type: float
    value domain: [0, 1]
    reference value: 0.30
    reference value status: NIST引用的受限路径最大额定速度比例。
    unit: ratio

    signal name: distance_to_obstacle
    signal message: 安全传感系统实测的车辆运动轮廓前缘到行驶方向上最近人员或障碍物的距离。
    signal role: measured obstacle distance
    type: float
    value domain: [0, +∞)
    unit: m

    signal name: minimum_safe_stopping_distance
    signal message: 根据当前速度、负载、路面、系统反应和制动性能确定的避免接触所需最小停车距离；它是派生安全阈值，不是实测障碍距离。
    signal role: derived safety threshold
    type: float
    value domain: [0, +∞)
    reference range: vehicle_and_operating_condition_specific
    unit: m

    signal name: obstacle_in_vehicle_contour
    signal message: 人员、测试件或障碍物是否已经进入由车辆、载荷和拖车共同占据或扫掠的运动轮廓区域；true表示存在直接接触风险。
    signal role: derived geometric hazard status
    type: bool
    value domain: {false, true}

    signal name: obstacle_within_stopping_distance
    signal message: 当前最近障碍距离是否小于或等于当前最小安全停车距离；true表示剩余距离已进入停车需求范围。
    signal role: derived hazard status
    type: bool
    value domain: {false, true}
    calculation: distance_to_obstacle <= minimum_safe_stopping_distance

    signal name: safety_sensor_object_detected
    signal message: 车辆安全传感器当前是否检测到路径内或邻近路径的人员、测试件或障碍物。
    signal role: sensor detection status
    type: bool
    value domain: {false, true}

    signal name: controlled_slowdown_active
    signal message: 车辆控制系统当前是否正在因慢速区、受限路径净距或动态障碍物执行受控减速。
    signal role: control response status
    type: bool
    value domain: {false, true}

    signal name: safety_stop_active
    signal message: 车辆安全控制系统当前是否正在保持或执行安全停车状态。
    signal role: safety response status
    type: bool
    value domain: {false, true}

reference predicates:
    predicate name: path_clearance_is_restricted
    predicate message: 当前路径净距小于受限路径判定阈值。
    predicate type: numeric comparison
    expression: path_clearance < restricted_path_clearance_threshold
    unit: m

    predicate name: mobile_robot_speed_within_restricted_path_limit
    predicate message: 当前车辆速度比例不超过受限路径配置上限。
    predicate type: numeric comparison
    expression: mobile_robot_speed_fraction <= restricted_path_speed_fraction_limit
    applicable when: path_clearance < restricted_path_clearance_threshold或车辆处于资料定义的危险环境

    predicate name: obstacle_is_outside_required_stopping_distance
    predicate message: 当前最近障碍距离大于车辆所需的最小安全停车距离。
    predicate type: numeric comparison
    expression: distance_to_obstacle > minimum_safe_stopping_distance
    unit: m

    predicate name: obstacle_is_within_stopping_distance
    predicate message: 当前障碍物已经进入车辆所需停车距离范围。
    predicate type: boolean comparison
    expression: obstacle_within_stopping_distance == true

    predicate name: obstacle_is_in_vehicle_contour
    predicate message: 障碍物已经进入车辆运动轮廓区域。
    predicate type: boolean comparison
    expression: obstacle_in_vehicle_contour == true

    predicate name: safety_sensor_detects_object
    predicate message: 车辆安全传感器当前检测到人员或障碍物。
    predicate type: boolean comparison
    expression: safety_sensor_object_detected == true

    predicate name: controlled_slowdown_is_active
    predicate message: 车辆当前正在执行受控减速。
    predicate type: boolean comparison
    expression: controlled_slowdown_active == true

    predicate name: safety_stop_is_active
    predicate message: 车辆当前正在执行或保持安全停车。
    predicate type: boolean comparison
    expression: safety_stop_active == true

behavior notes:
    note: 在危险环境或path_clearance小于restricted_path_clearance_threshold时，车辆速度应受restricted_path_speed_fraction_limit约束；0.5 m和0.30分别是参考资料中的判定值和上限配置，不是所有移动机器人的物理量程。

    note: 安全传感器检测、进入停车距离、受控减速和安全停车是不同阶段的信号；车辆必须在接触人员或测试物之前停车，具体响应期限应结合车辆测试条件在生成STL时加入。
