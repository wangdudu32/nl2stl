1. CCS TSI Appendix A – Mandatory specifications (ETCS B4 R1, RMR: GSM-R B1 MR1 + FRMCS B0, ATO B1 R1)

All the archived specifications are here.

Note 1: The points of the specifications listed in point 2.1 of EN 301 515 which are referenced in Index 32 and Index 33 as ‘MI’ are mandatory.
Note 2: The change requests (CRs) listed in table 1 and 2 of TS 102 281 which affect points referenced in Index 32 and Index 33 as ‘MI’ are mandatory.
Note 3: Index 48 refers only to test cases for GSM-R mobile equipment. It is kept reserved for the time being. When agreed in a future revision of the TSI, the catalogue of available harmonised test cases for the assessment of mobile equipment and networks, according to the steps indicated in point 6.1.2 of this TSI, will be introduced in these tables.
Note 4: The products which are on the market are already tailored to the needs of the RU related to GSM-R Driver Machine Interface and fully interoperable so there is no need for a standard in the TSI CCS.
Note 5: Information that was intended for index 78 is now incorporated in Index 27 (SUBSET-091).
Note 6: This document is ETCS, RMR and ATO baseline independent.
Note 7: Only the (MI) requirements are mandated by TSI CCS.
Note 8: These specifications, as regards to ETCS and ATO on board equipment, shall be fully implemented.
Note 9: These specifications, in their current version, as regards to FRMCS on-board equipment, are not considered complete for the purpose of tendering the on-board equipment.
