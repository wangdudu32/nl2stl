智能驾驶领域:
一、通用车辆信号池

这些信号几乎所有自动驾驶/车辆控制场景都可以用。

信号名	含义	单位/取值	适合构造的谓词
speed / velocity	车速	m/s, km/h	speed < 30
acceleration	纵向加速度	m/s²	acceleration > 2
deceleration	减速度	m/s²	deceleration > 3
jerk	加加速度，舒适性指标	m/s³	abs(jerk) < 2
brake	制动信号	0/1 或百分比	brake = 1
brake_pressure	制动压力	bar / %	brake_pressure > 60
throttle	油门开度	%	throttle < 20
steering_angle	方向盘转角	degree/rad	abs(steering_angle) < 15
yaw_rate	横摆角速度	deg/s	abs(yaw_rate) < 5
heading_angle	航向角	degree	abs(heading_error) < 3
mode	当前驾驶模式	枚举值	mode = ACC
system_active	系统是否激活	0/1	system_active = 1
warning_signal	警告信号	0/1	warning_signal = 1
driver_override	驾驶员接管	0/1	driver_override = 1
二、AEB：自动紧急制动场景

AEB 的核心是：前方有碰撞风险时，系统应及时制动或减速。

1. 推荐信号池
信号名	含义	类型	典型谓词
ego_speed	自车速度	状态	ego_speed > 30
relative_speed	自车与前车相对速度	环境/派生	relative_speed > 10
obstacle_distance	与障碍物距离	环境	obstacle_distance < 10
front_vehicle_distance	与前车距离	环境	front_vehicle_distance < 15
pedestrian_distance	与行人距离	环境	pedestrian_distance < 8
ttc	碰撞时间 Time-To-Collision	派生	ttc < 2.5
brake	是否制动	控制	brake = 1
brake_pressure	制动压力	控制	brake_pressure > 70
deceleration	减速度	状态	deceleration > 3
aeb_active	AEB 是否触发	模式/事件	aeb_active = 1
collision_warning	碰撞预警	事件	collision_warning = 1
collision_risk	碰撞风险等级	派生/状态	collision_risk > 0.8

2. 适合构造的自然语言需求
复制
当自车速度较高且前方障碍物距离过近时，AEB 系统应在短时间内触发制动。
对应信号：
复制
ego_speed > 30
obstacle_distance < 10
aeb_active = 1
brake = 1
￼

十三、建议你准备成这种结构
你后面让 LLM 填充随机 STL 模板时，不要只给它一个信号列表，而是给它一个场景知识卡片。
例如：
JSON
复制
￼
{
  "domain": "Autonomous Driving",
  "scenario": "AEB",
  "description": "Automatic Emergency Braking. The system should detect collision risk and trigger braking when the front obstacle is too close.",
  "signals": {
    "state": [
      "ego_speed",
      "acceleration",
      "deceleration"
    ],
    "environment": [
      "obstacle_distance",
      "front_vehicle_distance",
      "pedestrian_distance",
      "relative_speed",
      "ttc"
    ],
    "control": [
      "brake",
      "brake_pressure"
    ],
    "event_or_mode": [
      "aeb_active",
      "collision_warning",
      "collision_risk"
    ]
  },
  "recommended_predicates": [
    "ego_speed > 30",
    "obstacle_distance < 10",
    "ttc < 2.5",
    "brake = 1",
    "aeb_active = 1"
  ]
}
这样 LLM 生成数据时更稳定，因为它不仅知道有哪些信号，还知道这些信号之间的语义关系。
